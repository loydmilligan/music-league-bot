# Round Transition — Definition of Done

1. All required data checks pass before generation (submissions, votes, vote comments, round metadata are all green — chat-window mentions is optional)
2. Digest draft generated without errors (all sections returned, no failure list in the response)
3. HTML export URL returned and confirmed accessible (HTTP 200 on the URL)
4. League active round advanced to the next round, OR reason clearly reported if no next round was found
