# docs/

Documentation and design reference for Music League Bot.

## Directory index

| Path | What it is |
|------|-----------|
| `coordination/` | **Sprint process logs (orc-tower coordination) — process history, not product docs.** Decision records, sprint plans, and backlog for the orc-tower agent workflow. Do not delete — required by the orc coordination protocol. |
| `design/` | Claude/Mash Co. design handoff files — component fixtures, style tokens, and implementation prompts used during active sprints. |
| `design-briefs/` | Feature design briefs and wireframes for specific product features (chat watcher, digest preview, discoverability, shortlist). Current design references. |
| `superpowers/specs/` | Active implementation specs referenced by recent coordination docs. |
| `screenshots/` | UI screenshots captured during sprint verification — provenance record for visual changes. |
| `dev-loop-playbook.md` | Inner/outer loop deploy workflow (referenced in CLAUDE.md). |
| `HIGH_LEVEL_DESIGN.md` | System architecture overview. |
| `hip-jammers-s3-rounds.csv` | Reference data for the Hip Jammers league season 3. |
| `archive/` | **Historical artifacts — NOT current docs.** Planning, brainstorming, and early-sprint process files kept for provenance. See `archive/README.md`. |
