# Digest 2.0 — Phase ④b: Chat Relocation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the ML Stats "Chat" tab out of the digest2 Stats tab and into the digest2 **Chat section**: show three chat highlights (Talkativeness, Daily Activity, Roast Report) visible, with the rest of the chat visuals behind a "More chat stats" sub-tab, and remove the Chat tab from the embedded Stats explorer. The standalone `/boarz-stats` and `/stats` apps keep the full Chat tab unchanged.

**Architecture:** Decompose the three highlight sections out of the ~830-line `ChatTab.svelte` into three reusable, `{snap}`-prop components — `ChatTalkativeness`, `ChatRoastReport`, `ChatDailyActivity` (the last owns the only two pieces of ChatTab state: `actMode` and the `summaries` day-topics fetch). `ChatTab` renders them in place (behavior-preserving) and gains an opt-in `omitHighlights` prop (default false). A new `DigestChatStats.svelte` renders the three components + a sub-tab holding `<ChatTab omitHighlights/>`. The digest route mounts it under the chat story block and passes `omitTabs={['chat']}` to the Stats explorer (helper shipped in ④a).

**Tech Stack:** SvelteKit (Svelte 5 runes), Chart.js (`ChartCanvas`). Verified with `svelte-check` + production build against a DB copy (dev server hydration-crashes — [[project_digest_dev_hydration_crash]]).

**Spec:** `docs/superpowers/specs/2026-09-28-digest-2.0-design.md` §5.2; IA agreed 2026-10-01 (chat stats live with the chat narrative).

## Global Constraints

- **No regression to standalone stats apps.** `ChatTab` is mounted (via `StatsExplorer`) by `/stats/[league]` and `/boarz-stats`. The extraction must render the Chat tab identically there, and `omitHighlights` defaults to `false`. The three new components must reproduce their original sections exactly (configs, the `actMode` toggle, the `summaries` tooltip/peaks, the roast matrix).
- **The `summaries` day-topics fetch moves, it does not duplicate.** It lives in `ChatDailyActivity` (boarz-only, fail-quiet). `ChatTab` must no longer fetch it (its Daily Activity section is gone). Net: exactly one fetch wherever Daily Activity renders.
- **Read-only.** No DB writes; the only network call is the existing `/boarz-stats/api/day-topics` GET (decorative, guarded `snap.league.slug !== 'boarz-ii-men'` → skip; fails quiet).
- **Chat capability gating.** The digest chat-stats sub-area renders only when `snapshot.capabilities.chat` is true.
- `ChatTab`, `StatsExplorer` are shared symbols — edits are additive (new components + one defaulted prop).

## Review Focus

- **Standalone `/boarz-stats` Chat tab is visually identical** after the extraction (same three sections in the same place, same `actMode` toggle behavior, same roast matrix, same peak-day topic tooltips). (Tasks 1–3 own this; hand-verified against `/boarz-stats`.)
- **The `summaries` fetch fires exactly once** and still fills the Daily Activity peak tooltips; it never double-fetches and fails quiet off-boarz / under `STATS_ONLY`. (Task 3 owns this.)
- **A league with `capabilities.chat === false`** shows no chat-stats sub-area in the digest and no Chat tab in Stats, and does not crash. (Task 5 gates this; hand-verified on such a round if available, else reasoned from the gate.)
- **The embedded Stats tab has no Chat tab**, and the OTHER tabs (songs, heatmap, etc.) are unaffected. (Task 5 via `omitTabs={['chat']}`; hand-verified.)
- **`ChatTab omitHighlights` drops exactly the three highlights** and leaves Night Owl + all other sections intact (Night Owl's 2-up grid degrades to one column cleanly). (Task 4 owns this; hand-verified in the sub-tab.)

- [ ] **Step 1: Create `DigestChatStats.svelte`:**

```svelte
<script lang="ts">
	import type { Snapshot } from '$lib/server/boarzStats/data.js';
	import ChatTalkativeness from '$lib/components/boarzStats/ChatTalkativeness.svelte';
	import ChatDailyActivity from '$lib/components/boarzStats/ChatDailyActivity.svelte';
	import ChatRoastReport from '$lib/components/boarzStats/ChatRoastReport.svelte';
	import ChatTab from '$lib/components/boarzStats/ChatTab.svelte';

<section style="margin:1.5rem 0">
	<h2 style="font:700 1rem system-ui;margin:0 0 .5rem">Chat, by the numbers</h2>

		<ChatTalkativeness snap={snapshot} />
		<ChatDailyActivity snap={snapshot} />
		<ChatRoastReport snap={snapshot} />
	</div>
	<button
		type="button"

	{/if}
```
