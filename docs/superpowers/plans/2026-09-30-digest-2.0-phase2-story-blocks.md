# Digest 2.0 — Phase ② Story Blocks (reuse-first) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a complete-enough digest 2.0 page by REUSING an existing 1.0 draft's content — read the round's 1.0 story sections (podium, villain, chat, storylines) + Coinage read-only and render them in the 2.0 page above the Phase ① stats embed, reusing the 1.0 visual components. No generation, no writes.

**Architecture:** Approach A (fork, share read-side), reuse-first variant. A new `$lib/digest2/storyBlocks.ts` reads the newest 1.0 draft via the existing `getActiveDraftForRound`/`getSectionsForDraft` (read-only), filters to the auto story kinds, and returns parsed render blocks. The existing `/digest2/[roundId]` page (Phase ①) is extended to mount the 1.0 visual components (`AlbumPodium`, `ChatMoments`, `StorylinesCast`) for those blocks, plus simple cards for villain/coinage, with `digest.css` imported for styling. The stats embed from Phase ① stays below.

**Tech Stack:** SvelteKit (Svelte 5 runes), better-sqlite3, TypeScript, Vitest. Tests under `ui/`; run `cd ui && npx vitest run <path>`.

**Spec:** `docs/superpowers/specs/2026-09-28-digest-2.0-design.md` (Phase ②, reuse-first per 2026-09-30 decision).

## Global Constraints

- **Read-only.** No writes to any table, including `digest2_*`. This phase only READS the 1.0 `digest_drafts`/`digest_sections` (via `getActiveDraftForRound`/`getSectionsForDraft`) and the read-only stats snapshot.
- **Reuse, don't fork:** import the 1.0 readers from `$lib/digest/llm.js` and the 1.0 visual components from `$lib/digest/*.svelte`; do not copy their logic. Import `$lib/digest/digest.css` so the reused components are styled.
- **Auto story kinds only:** `podium`, `villain`, `chat`, `storylines`. `flow`/`consensus`/`quotes` are one-off (excluded here). Coinage is NOT a section row — it is `JSON.parse(draft.stats_content_json).phrase`.
- **No hardcoded hosts** (the `hostLiterals.test.ts` guard must stay green).
- Run gitnexus impact analysis before editing any *shared* symbol (none are edited — this phase adds files and extends the Phase ① route/loader).

## Review Focus

- **Round with NO active 1.0 draft** → page must render (empty story area) and still show the stats embed, never crash. (Task 1 + Task 2 own this; tests added.)
- **A draft whose sections are all `excluded` or none are auto kinds** → empty story blocks, no crash. (Task 1 owns this; the main-seed test's `flow`+excluded rows prove the filter.)
- **`stats_content_json` with no `phrase`** → `coinage` is null, no crash. (Task 1 owns this; asserted.)
- **Malformed `content_json` / `stats_content_json`** (not valid JSON) → the offending block is skipped and coinage falls back to null, rather than throwing and blanking the whole page. (Task 1 owns this; dedicated test.)
- **Styling dependency** → the reused visual components rely on `digest.css` classes; omitting the import renders them unstyled. (Task 3 imports it; verified by hand, not a unit test.)

```ts
import type Database from 'better-sqlite3';
import { getActiveDraftForRound, getSectionsForDraft } from '$lib/digest/llm.js';

/** The auto story section kinds digest 2.0 reuses from the 1.0 draft. */
export const AUTO_STORY_KINDS = ['podium', 'villain', 'chat', 'storylines'] as const;
export type AutoStoryKind = (typeof AUTO_STORY_KINDS)[number];

export interface StoryBlock {
	kind: AutoStoryKind;
	content: unknown; // parsed content_json
	variant: string;
}

export interface Digest2Story {
	blocks: StoryBlock[];
	coinage: unknown | null; // parsed stats_content_json.phrase
}

function safeParse(json: string): unknown {
	try {
		return JSON.parse(json);
	} catch {
		return null;
	}
}

/**
 * Read the round's newest 1.0 draft (read-only) and return the auto story
 * blocks + Coinage, in section position order. Never writes; never throws on
 * malformed JSON (the bad block is skipped / coinage falls back to null).
 */
export function buildDigest2StoryBlocks(db: Database.Database, roundId: number): Digest2Story {
	const draft = getActiveDraftForRound(db, roundId);
	if (!draft) return { blocks: [], coinage: null };

	const auto = new Set<string>(AUTO_STORY_KINDS);
	const blocks: StoryBlock[] = [];
	for (const s of getSectionsForDraft(db, draft.id)) {
		if (!auto.has(s.kind) || s.state === 'excluded') continue;
		const content = safeParse(s.content_json);
		if (content == null) continue;
		blocks.push({
			kind: s.kind as AutoStoryKind,
			content,
			variant: (s as { variant?: string }).variant ?? 'both'
		});
	}

	const stats = safeParse(draft.stats_content_json) as { phrase?: unknown } | null;
	const coinage = stats?.phrase ?? null;
	return { blocks, coinage };
}
```

```ts
import type Database from 'better-sqlite3';
import type { Snapshot, StatsSelection } from '$lib/server/boarzStats/data.js';
import { buildStatsEmbedForRound } from './statsEmbed.js';
import { buildDigest2StoryBlocks, type Digest2Story } from './storyBlocks.js';

export interface Digest2Page {
	roundId: number;
	snapshot: Snapshot;
	story: Digest2Story;
}

/** Assemble the read-only digest 2.0 page: stats embed (Phase ①) + reused 1.0 story blocks. */
export function buildDigest2Page(
	db: Database.Database,
	roundId: number,
	buildSnapshot: (selection: StatsSelection) => Snapshot
): Digest2Page {
	const { snapshot } = buildStatsEmbedForRound(db, roundId, buildSnapshot);
	const story = buildDigest2StoryBlocks(db, roundId);
	return { roundId, snapshot, story };
}
```

```ts
import { getDb } from '$lib/db/client.js';
import { buildSnapshotCached } from '$lib/server/boarzStats/data.js';
import { buildDigest2Page } from '$lib/digest2/page.js';
import type { PageServerLoad } from './$types';

export const load: PageServerLoad = async ({ params }) => {
	const roundId = Number(params.roundId);
	if (!Number.isInteger(roundId) || roundId <= 0) throw error(400, 'bad round id');
	try {
		return buildDigest2Page(getDb(), roundId, buildSnapshotCached);

		throw error(404, 'round not found');
```
