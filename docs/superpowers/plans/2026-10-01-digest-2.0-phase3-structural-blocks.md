# Digest 2.0 — Phase ③ Structural Auto Blocks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render the five structural/deterministic auto blocks — Standings chart, Next-round teaser, Tastemaker, Guesser leaderboard, and the Reel — on the read-only digest 2.0 dev page, above the Phase ① stats embed and below the Phase ② story blocks, by importing the existing read-only suppliers and reusing the existing 1.0 visual components. No generation, no writes.

**Architecture:** Approach A (fork, share the read-side), continuing the Phase ② reuse-first pattern. A new `$lib/digest2/structuralBlocks.ts` calls four deterministic read-only suppliers fresh from `league.db` (`getStandings`, `getNextRound`, `getDiscoverability`, `getGuesserData`) plus reads the Reel's `reel_content_json` off the newest 1.0 draft (reuse-only, like Coinage), applies the same availability gates the 1.0 page uses, and returns a typed `Digest2Structural` whose fields are each `null` when the block should not render. `buildDigest2Page` (Phase ②) is extended to carry `structural`. The existing `/digest2/[roundId]` page mounts the 1.0 components (`StandingsChart`, `NextRoundPreview`, `TastemakerSection`, `GuesserLeaderboard`, `ReelSection`) for the non-null blocks. The stats embed stays below.

**Tech Stack:** SvelteKit (Svelte 5 runes), better-sqlite3, TypeScript, Vitest. Tests under `ui/`; run `cd ui && npx vitest run <path>`.

**Spec:** `docs/superpowers/specs/2026-09-28-digest-2.0-design.md` (§3 "Auto sections — Structural/deterministic"; Phase ③ per the 2026-10-01 scope decision: all 5 blocks, 4 computed fresh + Reel reused).

## Global Constraints

- **Read-only.** No writes to any table, including `digest2_*`. This phase only READS `league.db` game data (via the existing deterministic suppliers, each of which opens the DB read-only or is called on the shared read connection) and the newest 1.0 `digest_drafts` row for the Reel. Never writes.
- **Reuse, don't fork:** import the deterministic suppliers from `$lib/db/*.js` and `$lib/digest/guesserSection.js`, and the visual components from `$lib/digest/*.svelte`; do not copy their logic. `$lib/digest/digest.css` is already imported by the Phase ② page.
- **Compute fresh for the 4 deterministic blocks** (standings, next-round, tastemaker, guesser): call the supplier directly, not via a self-`fetch` to `/api/digest/*` (the 1.0 page fetches; the 2.0 loader calls the same functions the endpoints wrap). **Reel is reuse-only:** read `digest_drafts.reel_content_json` from the newest draft.
- **Never let one supplier failure blank the page:** each supplier call is individually wrapped so a throw yields `null` for that block, never an exception out of `buildDigest2Structural`.
- **Gates mirror the 1.0 page** (`ui/src/routes/digest/[roundId]/+page.svelte`): standings shown only when `standings.standings.length > 0`; tastemaker only when `players.length > 0`; guesser only when the league is opted in AND `guesserName` is set AND `weekly.attempts > 0`; next-round only when the supplier returns non-null; reel only when `reel_state !== 'excluded'` AND (`media.poster` or `media.src`) is present.
- **No hardcoded hosts** (the `hostLiterals.test.ts` guard must stay green).
- No *shared* symbol is edited (this phase adds files and extends the Phase ② loader/route), so no gitnexus impact analysis is required; run `detect-changes` before each commit per repo convention.

## Review Focus

- **Brand-new round with no votes/submissions** → every structural block absent (all five `null`), page still renders the stats embed, never crashes. (Task 1 owns this; the empty-seed test asserts all-null.)
- **League NOT opted into the Guesser** → guesser block absent even though the round exists. (Task 1 owns this; the empty-seed DB has no guesser settings row, so `guesserSectionEnabledFor` is false → null; asserted.)
- **Reel `reel_state = 'excluded'`** → reel absent even though `media` is present. (Task 1 owns this; dedicated test.)
- **Malformed `reel_content_json`** (not valid JSON) → reel is `null`, no throw. (Task 1 owns this; dedicated test.)
- **One deterministic supplier throws** (e.g. an unexpected round shape makes `getStandings` throw) → that block is `null` and the other four still resolve, rather than the whole page 500ing. (Task 1 owns this; the per-supplier try/catch is covered by an injected-throw test.)

```ts
import type Database from 'better-sqlite3';
import { getStandings, type StandingsResult } from '$lib/db/standings.js';
import { getNextRound, type NextRoundPreview } from '$lib/db/nextRound.js';
import { getDiscoverability, type TastemakerPayload } from '$lib/db/discoverability.js';
import { getGuesserData, type GuesserData } from '$lib/db/guesserInsights.js';
import { guesserSectionEnabledFor } from '$lib/digest/guesserSection.js';
import { getActiveDraftForRound } from '$lib/digest/llm.js';

/** Parsed `digest_drafts.reel_content_json` (shapes vary by draft; read defensively). */
export interface ReelContent {
	title?: string;
	note?: string;
	media?: { src?: string; poster?: string };
}

export interface Digest2Structural {
	standings: StandingsResult | null;
	nextRound: NextRoundPreview | null;
	tastemaker: TastemakerPayload | null;
	guesser: GuesserData | null;
	reel: ReelContent | null;
}

/** The read-only suppliers this module calls. Overridable in tests to inject a throw. */
export interface StructuralSuppliers {
	getStandings: typeof getStandings;
	getNextRound: typeof getNextRound;
	getDiscoverability: typeof getDiscoverability;
	getGuesserData: typeof getGuesserData;
	guesserSectionEnabledFor: typeof guesserSectionEnabledFor;
	getActiveDraftForRound: typeof getActiveDraftForRound;
}

const DEFAULT_SUPPLIERS: StructuralSuppliers = {
	getStandings,
	getNextRound,
	getDiscoverability,
	getGuesserData,
	guesserSectionEnabledFor,
	getActiveDraftForRound
};

/** Run a supplier, returning `fallback` (default null) if it throws. */
function safe<T>(fn: () => T, fallback: T): T {
	try {
		return fn();
	} catch {
		return fallback;
	}
}

function leagueSlugForRound(db: Database.Database, roundId: number): string | null {
	const row = db
		.prepare(
			`SELECT l.slug AS slug
			   FROM rounds r
			   JOIN seasons s ON r.season_id = s.id
			   JOIN leagues l ON s.league_id = l.id
			  WHERE r.id = ?`
		)
		.get(roundId) as { slug?: string } | undefined;
	return row?.slug ?? null;
}

/**
 * Build the five structural/deterministic auto blocks for a round, read-only.
 * Each field is null when its block should not render (no data / not opted in /
 * excluded). Four blocks compute fresh from league.db; the Reel is reused from
 * the newest 1.0 draft's reel_content_json. A supplier that throws yields null
 * for that block only — never an exception out of this function.
 */
export function buildDigest2Structural(
	db: Database.Database,
	roundId: number,
	overrides: Partial<StructuralSuppliers> = {}
): Digest2Structural {
	const s = { ...DEFAULT_SUPPLIERS, ...overrides };

	const standings = safe<StandingsResult | null>(() => {
		const r = s.getStandings(db, roundId);
		return (r.standings?.length ?? 0) > 0 ? r : null;
	}, null);

	const nextRound = safe<NextRoundPreview | null>(() => s.getNextRound(db, roundId) ?? null, null);

	const tastemaker = safe<TastemakerPayload | null>(() => {
		const r = s.getDiscoverability(db, roundId);
		return (r?.players?.length ?? 0) > 0 ? r : null;
	}, null);

	const guesser = safe<GuesserData | null>(() => {
		const slug = leagueSlugForRound(db, roundId);
		if (!slug || !s.guesserSectionEnabledFor(db, slug)) return null;
		const g = s.getGuesserData(db, roundId);
		return g.guesserName && g.weekly.attempts > 0 ? g : null;
	}, null);

	const reel = safe<ReelContent | null>(() => {
		const draft = s.getActiveDraftForRound(db, roundId) as
			| { reel_state?: string; reel_content_json?: string }
			| null;
		if (!draft || draft.reel_state === 'excluded') return null;
		const raw = draft.reel_content_json;
		if (!raw) return null;
		const content = JSON.parse(raw) as ReelContent;
		const hasMedia = !!(content.media?.poster || content.media?.src);
		return hasMedia ? content : null;
	}, null);

	return { standings, nextRound, tastemaker, guesser, reel };
}
```

> Note on `guesser`: the `GuesserData` field names (`guesserName`, `weekly.attempts`) are taken from the gate in `ui/src/routes/digest/[roundId]/+page.svelte` (`showGuesser`). If `svelte-check`/`vitest` reports a property mismatch, open `ui/src/lib/db/guesserInsights.ts` (`interface GuesserData`, line ~105) and correct the property path to match — do not change the gate's intent (opted-in + a detected guesser + ≥1 attempt this week).
