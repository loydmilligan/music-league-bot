# Digest 2.0 — Phase ① Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the isolated `digest2_*` database tables and a read-only stats embed behind an unlinked dev route `/digest2/[roundId]`, proving the read-side sharing works without touching the live digest.

**Architecture:** Approach A (fork, share the read-side). This phase adds *only new* tables via `CREATE TABLE IF NOT EXISTS` in the shared schema, and a new `$lib/digest2/` module plus a dev route that reads `league.db` read-only and embeds the existing (read-only) Boarz Stats Explorer. No writes to any 1.0 table, queue, volume, or the Caddy host.

**Tech Stack:** SvelteKit (Svelte 5 runes), better-sqlite3, TypeScript, Vitest. UI code + tests live under `ui/`; run tests with `cd ui && npx vitest run <path>`.

**Spec:** `docs/superpowers/specs/2026-09-28-digest-2.0-design.md` (read it — this plan implements §4–5 Phase ①).

## Global Constraints

- **Never edit the live 1.0 tables** `digest_drafts` / `digest_sections` / `digest_regenerations` / `digest_jobs` / `digest_sends` / `digest_shares`, nor their boot migrations in `ui/src/lib/db/client.ts`. This phase only *appends* new `CREATE TABLE IF NOT EXISTS digest2_*` statements to the `SCHEMA` string.
- **`digest2_sections.kind` has NO CHECK constraint** — 2.0 owns its own section kinds; a CHECK here is a defect.
- **Read-only for game data.** 2.0 reads `league.db`; the only tables it may ever write are `digest2_*` (no writes at all in this phase).
- **No hardcoded hosts.** Reuse `$lib/config/urls.ts` if a URL is ever needed (none in this phase). The existing `hostLiterals.test.ts` guard must stay green.
- **Do not import or fork** the boarz-stats compute — import `buildSnapshotCached` and use it as-is (it already opens the DB `readonly:true`).
- Repo convention: run gitnexus impact analysis before editing any *shared* symbol (none are edited here — this phase adds files and appends schema).

## Review Focus

- **Unknown or non-integer `roundId`** → the route must answer 404/400, never 500 or a crash. (Task 3 owns this; test added there.)
- **A round whose season has no completed rounds yet** → the snapshot's arrays are empty; the page must render without throwing. (Task 3 owns this; empty-snapshot test added there.)
- **Cross-season league** → the embed must scope to the *round's own season*, not `'all'` and not the wrong season. (Task 2 owns this; test asserts the exact `seasons:[n]`.)
- **Schema drift risk** → adding `digest2_*` must not alter the live `digest_sections.kind` CHECK. (Task 1 owns this; explicit assertion test.)
- **Season-scoped vs round-scoped** → the snapshot is season-to-date, not capped at the round; early-round digests legitimately show the whole season-so-far. This is accepted per spec §5.2, not a bug — no test, documented here so a reviewer does not "fix" it.

```ts
import type Database from 'better-sqlite3';
import type { StatsSelection } from '$lib/server/boarzStats/data.js';

/**
 * Map a round id to the read-only Boarz-stats selection for its OWN season.
 * Returns null if the round does not exist.
 */
export function resolveStatsSelectionForRound(
	db: Database.Database,
	roundId: number
): StatsSelection | null {
	const row = db
		.prepare(
			`SELECT l.slug AS leagueSlug, s.season_number AS seasonNumber
			   FROM rounds r
			   JOIN seasons s ON s.id = r.season_id
			   JOIN leagues l ON l.id = s.league_id
			  WHERE r.id = ?`
		)
		.get(roundId) as { leagueSlug: string; seasonNumber: number } | undefined;
	if (!row) return null;
	return { leagueSlug: row.leagueSlug, seasons: [row.seasonNumber] };
}
```

```ts
import type Database from 'better-sqlite3';
import type { Snapshot, StatsSelection } from '$lib/server/boarzStats/data.js';
import { resolveStatsSelectionForRound } from './statsSelection.js';

/**
 * Build the read-only stats embed for a round: resolve its own-season selection
 * and hand it to the (injected) snapshot builder. Throws if the round is unknown.
 */
export function buildStatsEmbedForRound(
	db: Database.Database,
	roundId: number,
	buildSnapshot: (selection: StatsSelection) => Snapshot
): { roundId: number; snapshot: Snapshot } {
	const selection = resolveStatsSelectionForRound(db, roundId);
	if (!selection) throw new Error(`round ${roundId} not found`);
	return { roundId, snapshot: buildSnapshot(selection) };
}
```

```ts
import { error } from '@sveltejs/kit';
import { getDb } from '$lib/db/client.js';
import { buildSnapshotCached } from '$lib/server/boarzStats/data.js';
import { buildStatsEmbedForRound } from '$lib/digest2/statsEmbed.js';
import type { PageServerLoad } from './$types';

export const load: PageServerLoad = async ({ params }) => {
	const roundId = Number(params.roundId);
	if (!Number.isInteger(roundId) || roundId <= 0) throw error(400, 'bad round id');
	try {
		return buildStatsEmbedForRound(getDb(), roundId, buildSnapshotCached);
	} catch {
		throw error(404, 'round not found');
	}
};
```
