# Rulecard — Second Best (slug: second-best)

Verified 2026-08-16 from Matt + R139 ballots. Load this before writing ANY
digest content for this league. Numbers in digest copy must be recomputed from
`votes`, never inferred.

## Voting mechanics
- Each voter files ONE ballot, all at once. Voting does NOT happen throughout
  the week. Never write copy implying incremental voting.
- Budget through R139: **11 upvotes + 1 MANDATORY downvote** per voter.
- Budget from R140 on: **12 upvotes + 1 mandatory downvote** (announced by
  Matt 2026-08-11 after Michael Black joined).
- Per-song max: **6 points** from one voter.
- A comment with **no points attached is NOT a downvote** and signals nothing
  beyond an unrewarded opinion. Do not frame 0-point comments as votes against.
- Submitters may comment on their own song (0 points).

## No-vote penalty
If a submitter never files a ballot: **all upvotes their song received are
voided; downvotes still count.** (R139: Joe Quinto — 13 upvote points voided,
official total −1.)

## Tiebreakers (round), in order — High Stakes Mode is NOT used here
1. Total points (upvotes + downvotes).
2. More upvoters wins.
3. Fewer downvoters wins.
4. Vote weight sequence, compared highest→lowest until a difference.
If still tied: shared rank, listed alphabetically. (R139 Juicy / Bottle of
Smoke: first true tie observed — identical through all four steps.)

## League standings tiebreakers
Total points → more total upvoters → fewer total downvoters → shared rank.
