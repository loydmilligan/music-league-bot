## Voting mechanics
- Each voter files ONE ballot, all at once.
- Budget: **8 upvote points** per voter (R145 on). R135 was 7 — the budget
  rose between seasons of play; a `voting_lab_budget` round override pins
  R135 at 7. Every ballot in every observed round spends the budget exactly.
- Downvotes: **up to 2** per voter. Observed: most file 2, some file 1
  (R147: six voters filed 2, three filed 1). UNRESOLVED: is 2 mandatory or
  a maximum? Treat as a maximum until Matt says otherwise.
- Per-song max from one voter: **4** (stored cap; observed max is 4, with
  3 the common top weight).
- A comment with no points attached is NOT a downvote.

## No-vote penalty
If a submitter never files a ballot: **upvotes voided, downvotes stand** —
same rule as Second Best. Precedent R147: Grant Koziol filed no ballot;
"You Oughta Know" earned 5 up / −5 down, official −5.
