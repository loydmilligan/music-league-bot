# Spec — MLB playlist page, interactive layer

**Source:** `design/mlb-playlist-brief.md` → CD packet (`design_handoff_mlb_playlist/`) →
`design/mlb-playlist-handoff-review.md`. Decisions below are settled; build to them.

## Context

A per-round music-video playlist published as a **single static HTML file** at
`digest.mattmariani.com/p/<slug>/`, generated by `ui/src/lib/ytm/playlistPage.ts`. Public, no
auth, phone-first, arrived at from a WhatsApp link. The page is served by a dumb Caddy over a
read-only volume — **no framework, no build step, inline CSS + inline JS only**.

Already built and NOT to be changed by this work:
- `ui/src/lib/ytm/videoReview.ts` — the data model (CC owns it; do not edit)
- `ui/src/lib/ytm/videoCover.ts` — the WhatsApp share flyer
- `ui/src/lib/ytm/send.ts`, `youtube.ts`, `reviewContext.ts`
- `ui/src/routes/ytm/[roundId]/videos/` — the Matt-only curation screen

## Settled decisions

| # | Decision |
|---|---|
| D1 | Share art = heavy-xerox flyer. **Done.** |
| D2 | Identity = **persistent chip** in the header. Read freely; pick who you are from the 13-player roster; persists in `localStorage`. Never a gate. |
| D3 | Thumbs up **and** down, tallies visible. **Superseded stamp** — see Band stamp. |
| D4 | Provenance shown as **words, not percentages**: `comment`→`THEIR PICK` (moss), `search ≥70`→`WE FOUND THIS` (sky), `search 45–69`→`BEST GUESS` (amber), `search <45`→`A GUESS` (ember), candidate `manual`→`ADDED BY HAND` (fg-muted). Raw score stays admin-only. |
| D5 | Playback = tap a thumbnail to embed in place. Must survive embed-forbidden and deleted videos. |
| D6 | **Primary + children.** `pick.chosen[0]` is the primary — it represents the song and is the **only votable** video. `chosen[1..]` are children: collapsed by default, indented, commentable, **never votable**. |

## The band stamp (decorative easter egg)

Four players each own an instrument and a colour. **Everyone else's upvote just counts.**

| Player | Colour | Instrument |
|---|---|---|
| Matt Mariani | blue | guitar |
| Jon Black | red | mic |
| Brian Pascoe | black | bass |
| TJ Cook | green | drums |

- Each of the four has **one** stamp, spent on the **first video they thumb up**. Later upvotes
  count but carry no stamp.
- Apart: one instrument alone on a video — sparse, deliberately incomplete.
- Together: instruments **assemble** into a band; all four = full colour and detail.
- It **means nothing**. No text equivalent needed; the `▲ n` count is the real data.
- Brian Pascoe's black on `--ink-0 #07090c` is a known legibility trap — solve it (outline,
  lighter ink, or a paper patch behind the stamp).

## Data model (read-only for this work)

```ts
VideoPick { title, artists, spotifyUri,
            source: 'comment'|'search'|null, score, band,
            candidates: VideoCandidate[],   // { videoId, title, channel, score, manual? }
            chosen: string[],               // [0] = primary, [1..] = children
            included, decided, reason }
```
Helpers already exported from `videoReview.ts`: `primaryVideoId`, `childVideoIds`,
`withPrimary`, `includedVideoIds`.

## Contract between slices

`bandStamp.ts` exports, and `playlistPage.ts` consumes:

```ts
export type BandMember = 'matt' | 'jon' | 'brian' | 'tj';
export const BAND: Record<BandMember, { player: string; colour: string; instrument: string }>;
/** Inline SVG for the stamp formed by these members. Empty string for none. */
export function bandStampSvg(members: BandMember[], opts?: { size?: number }): string;
```

`playlistVotes.ts` exports, and the endpoints consume:

```ts
export interface VoteTally { videoId: string; up: number; down: number; stampers: BandMember[] }
export function ensurePlaylistSchema(db): void;
export function castVote(db, slug, videoId, playerId, dir: 'up'|'down'|null, now): void;
export function tallies(db, slug): VoteTally[];
export function submitMessage(db, slug, videoId, playerId, text, now): { id: number };
export function pendingMessages(db, slug): Message[];   // approved only, for the page
```

## Hard constraints

- Page = one self-contained file. External assets: the shared font stylesheet and
  `i.ytimg.com` thumbnails **only**.
- Votes/messages need a public write path: Caddy reverse-proxies a narrow prefix on
  `digest.mattmariani.com` to bot-ui. Keep the number of distinct write actions small.
- Messages **queue for Matt's approval** and post to WhatsApp only when he releases them —
  same shape as the existing video-review approval. They never post directly.
- Hit targets **≥44px**. 4.5:1 on body text. No colour-only encoding of vote state.
- Tokens: Mash Co music-league slice. Pulp `#ff5b2e`; ink ramp `#07090c`→`#f1f4f7`; fonts
  Bricolage Grotesque / Inter Tight / JetBrains Mono.

## Out of scope

Live cross-client updates, comment threads, the challenge-question identity idea, and anything
deriving location from IP addresses.
